# OCR Text Control ✨

A smart OCR-powered tool for extracting and copying text from images, designed to give users advanced control over what and how they copy.

## 🚀 Features

- 📷 Image to Text: Extracts clean, selectable text from screenshots and images.
- 🧠 Smart Copy: Allows partial selection, formatting retention, and structured output.
- 🖥️ Web-Based UI: Intuitive frontend built for ease of use.
- ⚙️ Backend Processing: Powered by Python OCR libraries for fast, accurate recognition.

## 🛠️ Tech Stack

- Frontend: HTML, CSS, JavaScript (React)
- Backend: Python (Flask/FastAPI), Tesseract OCR
- Version Control: Git & GitHub
